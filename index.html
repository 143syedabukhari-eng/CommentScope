Privacy Policy for Comment Scope

Effective Date: February 20, 2024

Last Updated: February 20, 2024

Comment Scope ("we," "us," or "our") is committed to protecting your privacy. This Privacy Policy explains how our Chrome Extension, Comment Scope: YouTube AI Analyzer & Scraper, handles data.

1. Overview

Comment Scope is an audience intelligence tool designed to analyze YouTube comments, transcripts, and video descriptions using AI. The extension operates on a "User-Owned Data" model, meaning we do not host servers to store your personal data or API keys.

2. Information Collection and Use

We do not collect any personally identifiable information (PII).

  • API Keys: To function, the extension requires API keys for YouTube (Google Cloud), Groq, or Gemini. These keys are provided by you and are stored locally in your browser's chrome.storage.local. We never see, store, or transmit these keys to our own servers.
  • Analysis History: Your analysis history (video titles and dates) is stored locally on your device to provide a seamless user experience.
  • Feedback Data: If you use the "Feedback" feature, the information you provide (message, Video ID, and Video Title) is sent to us via Formspree so we can improve the extension. This is the only time data is transmitted to us, and it is done only with your explicit action.

3. Use of Permissions

To provide its core features, Comment Scope requires the following permissions:

  • activeTab: Used to detect the URL of the YouTube video you are currently watching so the extension can fetch the correct comments and transcript.
  • storage: Used to save your settings, API keys, and local analysis history on your computer.
  • tabs: Used to communicate between the extension popup and the YouTube page to facilitate comment scraping and transcript extraction.
  • Host Permissions: Required to allow your browser to communicate directly with the AI and YouTube services (googleapis.com, groq.com, etc.) using your provided API keys.

4. Third-Party Services

Our extension communicates directly with the following third-party APIs:

  • Google YouTube Data API
  • Google Gemini API / Groq API

These services have their own privacy policies. Data sent to these APIs is limited to the text of comments, transcripts, and descriptions required for analysis.

5. Data Security

Because all data (including API keys) is stored locally in your browser's secure storage, your data is as secure as your computer and browser. We do not have access to your data and cannot see your analysis results.

6. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected by the "Last Updated" date at the top of this page.
